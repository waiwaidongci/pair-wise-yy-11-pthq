# StateBoard 状态机可视化编辑器

技术栈：React、TypeScript、Vite、React Flow、XState、MUI、Zustand、React Router。

## 功能

- 在画布上添加普通状态、复合状态、子状态和结束状态，通过连线创建转移。
- 复合状态可容纳多条**并行支路**：进入时每条支路各自从标了初始的子状态起步，事件广播给当时所有激活的支路，某条支路先到结束不拖住其余支路，等每条支路都到达结束才算整体完成。
- 同一事件在同一条支路上命中多条转移时按守卫优先级取一条（有守卫优先于无守卫），排不出先后就在轨迹里标出冲突。
- 每条转移可配置事件、守卫条件、动作和上下文变量赋值。
- 结构、转移或上下文一有改动，正在跑的并行模拟自动作废重算，免得沿用旧激活结果。
- 校验不可达状态、缺少转移、复合状态缺初始子状态、空复合状态、支路缺初始项和重复事件。
- 模拟面板可按事件逐步执行，实时显示所有激活状态、上下文和完整事件轨迹。
- 旧版数据导入时自动把单支路补成一条并行支路；导出可编译的 XState 配置（复合状态写为 `type: 'parallel'`）、Mermaid `stateDiagram-v2` 和完整状态机 JSON。

## 运行

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm build
```
