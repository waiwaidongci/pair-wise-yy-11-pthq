# StateBoard 状态机可视化编辑器

技术栈：React、TypeScript、Vite、React Flow、XState、MUI、Zustand、React Router。

## 功能

- 在画布上添加普通状态、复合状态、子状态和结束状态，通过连线创建转移。
- 复合状态可容纳多条并行支路：进入时每条支路各自从标了初始的子状态起步，事件广播给所有激活支路；某条支路先到结束不拖住其余支路，每条支路都到达结束才整体完成，随后触发从复合状态边框连出的 `DONE` 完成转移。
- 每条转移可配置事件、守卫条件、守卫优先级、动作和上下文变量赋值。同一事件在同一条支路上命中多条转移时按守卫优先级取一条；优先级排不出先后会在事件轨迹中标出冲突。
- 校验不可达状态、缺少转移、支路缺初始子状态、空支路、并行复合状态只有一条支路、缺完成转移和重复事件。
- 模拟面板按事件逐步执行，实时显示上下文、所有激活支路和每条支路的完整事件轨迹。
- 结构、转移或上下文定义一有改动，正在运行的并行模拟立即作废并回到初始重算。
- 导出按并行结构（XState `type: 'parallel'` 多 region）编写的可编译配置、Mermaid `stateDiagram-v2` 和 v2 状态机 JSON；导入 v1 旧数据时自动把原单支路升级为一条并行支路。

## 运行

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm build
```
